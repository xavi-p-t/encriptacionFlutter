# Herramienta de Encriptación y Desencriptación RSA 🔒

¡Bienvenido a la página oficial de la aplicación! Esta herramienta permite proteger tus archivos locales utilizando criptografía asimétrica RSA.

## Descargar la Aplicación
Para instalar la aplicación en Windows, descarga el instalador desde nuestra sección de Releases:

**[Descargar instalador (.msix) para Windows](AQUÍ_PEGA_EL_LINK_DE_DESCARGA_DE_TU_RELEASE)**

## Cómo utilizarla
### Encriptar un archivo:
1. Abre la aplicación.
2. Selecciona tu clave pública `.pem`.
3. Elige el archivo que quieres proteger.
4. Haz clic en "Encriptar archivo". Se generará un archivo `.enc` seguro.

### Desencriptar un archivo:
1. Selecciona tu clave privada `.pem`.
2. Elige el archivo `.enc` que deseas abrir.
3. Selecciona la carpeta y el nombre donde quieres guardar el archivo descifrado.
4. Haz clic en "Desencriptar archivo".
